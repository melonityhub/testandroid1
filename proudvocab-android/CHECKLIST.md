# چک‌لیست کیفیت و رفع خطا — ProudVocab Android

## الف) چیزهایی که خودکار چک میشن (هر بیلد در GitHub Actions)

| # | چک | کجا اجرا میشه | اگر خطا داد |
|---|----|---------------|-------------|
| 1 | همهٔ `R.string` / `R.drawable` استفاده‌شده تعریف شده باشن؛ رشته‌های فارسی و انگلیسی هم‌کلید باشن؛ XML ها معتبر باشن | `tools/check_resources.py` | پیام خطا دقیقاً اسم منبع گم‌شده رو می‌گه |
| 2 | مانیفست فقط **یک** مجوز داشته باشه (`INTERNET`) و هیچ کدی از `READ/WRITE_EXTERNAL_STORAGE` یا منطق لایسنس/پریمیوم استفاده نکنه | همان اسکریپت | آن خط رو حذف کن/به من بگو |
| 3 | ۴۹ تست واحد (زیرنویس SRT/VTT/ASS، انکدینگ فارسی، CEFR، SRS، بازی‌ها، خروجی CSV/Anki، JSON) | `./gradlew testDebugUnitTest` | لاگ تست در آرتیفکت `build-failure-logs` |
| 4 | کامپایل کامل و ساخت APK ریلیز | `./gradlew assembleRelease` | لاگ در `build-failure-logs` |
| 5 | امضای APK معتبر باشد، `minSdk = 28` (اندروید ۹) باشد، مجوزها فقط `INTERNET` باشد | مرحلهٔ «Verify the APK» | بیلد fail میشه و دلیلش چاپ میشه |

## ب) تست دستی روی POCO X3 Pro (۱۰ دقیقه، بعد از نصب هر نسخهٔ جدید)

1. **نصب:** APK رو از Releases دانلود و نصب کن (اجازهٔ «نصب از منابع ناشناس» برای مرورگر/فایل‌منیجر).
2. **مجوزها:** تنظیمات ← برنامه‌ها ← ProudVocab ← مجوزها: باید «هیچ مجوزی درخواست نشده» باشه (اینترنت مجوز زمان نصبه و پرسیده نمیشه).
3. **باز کردن فایل:** کتابخانه ← «باز کردن ویدیو و زیرنویس» ← هر دو فایل (mp4/mkv + srt) رو با هم انتخاب کن ← ویدیو پخش میشه و زیرنویس زیرش میاد.
4. **کلیک روی کلمه:** ویدیو متوقف میشه، ترجمه و سطح CEFR میاد، «ذخیرهٔ کلمه» کار می‌کنه، با بستن کارت ویدیو ادامه پیدا می‌کنه.
5. **چرخش صفحه:** دکمهٔ تمام‌صفحه ← حالت افقی، کنترل‌ها بعد ۴ ثانیه محو میشن، با لمس برمی‌گردن؛ ویدیو قطع نمیشه.
6. **ادامه از جای قبلی:** برنامه رو ببند (حتی از لیست اخیر)، دوباره باز کن ← همان ویدیو از همان نقطه شروع میشه.
7. **لغت‌ها:** کلمهٔ ذخیره‌شده هست؛ جستجو، «یادگرفته»، «سخت»، ویرایش و حذف کار می‌کنن.
8. **مرور (SRS):** تمرین ← مرور ← کارت‌ها نمایش داده میشن؛ «دوباره» همان کارت رو آخر صف برمی‌گردونه.
9. **بازی‌ها:** با حداقل ۴ کلمه هر ۶ بازی شروع میشن؛ دیکته صدا می‌خونه (نیاز به Speech Services by Google).
10. **خروجی:** لغت‌ها ← ⋮ ← CSV / Anki / پشتیبان JSON ← فایل در محل انتخابی ذخیره میشه؛ «بازیابی از پشتیبان» همان فایل رو برمی‌گردونه.
11. **بدون اینترنت:** حالت هواپیما ← ویدیو و زیرنویس و لغت‌های ذخیره‌شده کار می‌کنن؛ فقط ترجمهٔ کلمهٔ جدید پیغام «آفلاین» می‌ده و می‌تونی دستی بنویسی.

## ج) اگر خطایی پیش اومد

**بیلد در GitHub fail شد**
1. Actions ← اجرای قرمز ← پایین صفحه، بخش *Artifacts* ← `build-failure-logs` رو دانلود کن.
2. همون فایل (یا فقط ۳۰ خط آخر `build.log` که با `error:` شروع میشه) رو برای من بفرست؛ علت رو پیدا و اصلاح می‌کنم.

**اپ روی گوشی بسته شد (crash)**
- اپ رو دوباره باز کن ← تنظیمات ← «نمایش گزارش آخرین خطا» ← کپی ← برای من بفرست. مدل گوشی/نسخهٔ اندروید هم توی گزارش هست.

**خطاهای رایج و علاجشون**

| علامت | علت محتمل | راه‌حل |
|-------|-----------|--------|
| «برنامه نصب نشد / تداخل با برنامهٔ قبلی» | کلید امضا با نسخهٔ قبلی فرق داره (کلید موقت) | یک‌بار ورک‌فلو *Generate signing keystore* رو بزن و ۴ Secret رو اضافه کن؛ این دفعه نسخهٔ قبلی رو پاک کن (قبلش از لغت‌ها پشتیبان JSON بگیر) |
| ویدیو پخش نمیشه، «خطا در پخش» | کدک/کانتینر پشتیبانی‌نشده (مثلاً AVI قدیمی یا DTS-only) | ویدیو رو به MP4/H.264 تبدیل کن؛ MKV و HEVC عموماً مشکلی ندارن |
| زیرنویس فارسی/ترکی خراب نمایش داده میشه | انکدینگ غیر UTF-8 | برنامه خودش UTF-8 / UTF-16 / windows-1256 رو تشخیص میده؛ اگر باز خراب بود فایل رو برام بفرست |
| ترجمه نمیاد | اینترنت قطع یا محدودیت موقت گوگل | چند ثانیه بعد دوباره؛ می‌تونی ترجمه رو دستی بنویسی و ذخیره کنی |
| دیکته/تلفظ صدا نداره | موتور TTS یا صدای انگلیسی نصب نیست | Speech Services by Google رو نصب و صدای English رو دانلود کن |
| کلمه‌ها بعد از آپدیت رفتن | نسخه با کلید دیگه نصب شده و قبلی پاک شده | از پشتیبان JSON برگردون |
